# Compare overrides

> Overrides `MASTER.md` for `/compare`.

- Use a **grouped comparison table** as the source of truth (accessible, sortable by row).
- Optional visual: horizontal bars per metric for 2–3 players. Label values on the bars; never color-only.
- Radar charts are allowed only as a secondary visual with a table fallback. Default to table + bars.
- Empty state: explain that two players must be selected from the roster.
- Errors: `role="alert"` plus text, not color alone.
